# All News Journal - OriginKit Web App

Moderno portal web de notícias para o **All News Journal**, desenvolvido com os padrões de design do **[OriginKit](https://www.originkit.dev/)** utilizando **Next.js 15**, **React 19**, **Tailwind CSS** e **Framer Motion**.

---

## ✨ Funcionalidades Principais

- ⚡ **Hero Ticker Dinâmico**: Transição automática de notícias a cada 5 segundos com badge de palavra-chave, imagem em alta definição e barra contínua de manchetes urgentes (marquee).
- 🎙️ **Player de Podcast (Leo & Ana)**: Áudio neural sintetizado (`edge-tts`), visualizador de ondas sonoras animado, controle de velocidade (1x, 1.25x, 1.5x, 2x) e download direto.
- 📰 **Grid Editorial Bento**: Cadernos filtráveis (Mundo, Economia, Política, IA, Wellness, Cinema, Fofoca) com leitor em modal e compartilhamento rápido.
- 🛡️ **Painel de Agentes com Proteção por Senha**: Console restrito protegido por PIN (`3344`) com telemetria da frota de agentes e grafo interativo de dados.
- ✉️ **Inscrição Modal**: Modal com física de mola (Spring) para captação de assinantes para o disparo diário das 06:00 BRT.

---

## 🚀 Como Executar

### 1. Entrar na pasta do frontend
```bash
cd frontend
```

### 2. Instalar dependências (caso não tenha feito)
```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o site funcionando.

### 4. Build de produção
```bash
npm run build
npm run start
```
